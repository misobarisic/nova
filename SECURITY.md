# Security Policy

## Supported versions

Security fixes are made against the latest release and the current `main`
branch. Older versions may not receive backported fixes.

## Reporting a vulnerability

Please do not publish unpatched vulnerability details in a public issue or
discussion.

If GitHub's **Security → Report a vulnerability** option is available for this
repository, use it to send a private report. Otherwise, contact the maintainer
through [their GitHub profile](https://github.com/misobarisic) and ask for a
private reporting channel without posting technical details publicly.

Include, when available:

- the affected Nova version or commit and platform;
- the affected component or dependency;
- steps to reproduce and the potential impact; and
- relevant logs or a proof of concept, with private data and credentials removed.

Please allow time for investigation and a fix before sharing the report
publicly. There is no fixed response-time commitment at this stage.
