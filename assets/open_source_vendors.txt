THIRD-PARTY VENDOR INVENTORY

Nova project code is GPL-3.0-or-later. See the full root LICENSE included after
this inventory. The in-app catalog is generated for the actual Cargo target and
features; it lists all runtime Cargo crates and their selected SPDX license
terms. The following inventory covers native and asset components that are not
represented by Cargo metadata.

NOVA WORKSPACE CRATES
The core app packages below share GPL-3.0-or-later. The generated Cargo catalog
lists the complete runtime dependency set in Settings → About:
- nova (root package, src/)
- addons (crates/addons/)
- nova-ui (crates/ui/)
- nova-storage (crates/storage/)
- nova-config (crates/config/)
- nova-download (crates/download/)
- nova-torrent (crates/torrent/)
- nova-media (crates/media/)
- nova-providers (crates/providers/)
- nova-player (crates/player/)
- nova-sync (crates/sync/)

NATIVE RUNTIME
Android and Windows use mpv/FFmpeg built from pinned sources by Nix.
Their exact component versions and full native notices are appended from the
Nix dependency when building. Linux uses distribution-provided mpv/FFmpeg and X11.

BUNDLED FONTS
Roboto-Regular.ttf is bundled at assets/fonts/Roboto-Regular.ttf under
Apache-2.0. Its complete font notice is assets/fonts/LICENSE.txt and is
included below.

OFL-1.1. Its complete license is assets/fonts/NotoColorEmoji-LICENSE.txt and
