# Addon card action icons

These unmodified SVGs come from [Lucide](https://github.com/lucide-icons/lucide),
pinned to commit [`c29c276f16590cf017126671535ad8c792be64d8`](https://github.com/lucide-icons/lucide/tree/c29c276f16590cf017126671535ad8c792be64d8/icons).
They use the upstream 24 × 24 view box, rounded two-pixel strokes, and
`currentColor`; Nova applies its existing settings text tint at render time.

| File | Addon card action |
| --- | --- |
| `settings.svg` | Configure |
| `refresh-cw.svg` | Refresh |
| `arrow-up.svg` | Move up |
| `arrow-down.svg` | Move down |

The [Lucide license and upstream Feather notices](../player/LICENSE) are shared
with the player icons and are included in Nova’s bundled About licenses.
