# Navigation icons

These SVGs were supplied in `nova_nav_icons.zip`:

- `house.svg`: Home
- `compass.svg`: Discover
- `library-big.svg`: Library
- `ellipsis.svg`: More

The supplied grid icon is intentionally excluded. Both the phone bottom bar
and desktop/TV sidebar use these assets, recolored with their existing active
and inactive theme colors. Icon sizing and selection feedback stay shared with
the existing navigation controls.
