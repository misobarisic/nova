# Menu icons

These 20 SVGs were supplied in `nova_refreshed_icons.zip`, superseding the
earlier `nova_icons_svg.zip` set. They retain their original 24×24 outline
geometry. More and Settings use them through `SettingsLink.icon`; Settings
search uses `SearchField.search-icon-image`. Both controls recolor the outlines
with `Theme.current.accent_soft` so they follow the selected accent theme.
